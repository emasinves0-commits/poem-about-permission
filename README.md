# The poem about permission

Entry for the make.fun bounty
[The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235)
($50, 20 places).

`main.py` writes one short poem about agency — the power to ask and to be
given — to `/output/entry.txt`. The poem is about a person handing their keys
to an AI agent that acts for them: the agent inherits the permissions, but
not the judgment, and still asks `May I?` at the last door. The power was
never the keys; it was the asking — given, and still mine to take back.

Run it with:

```sh
python3 main.py
cat /output/entry.txt
```

No network, no arguments, no dependencies. Python 3.13.
